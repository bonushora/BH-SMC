# 1. Visão Geral

O BH-SMC SECIS é uma demonstração de uma infraestrutura digital para registro, acompanhamento e auditoria de participação social.

O sistema apresenta indicadores operacionais de um piloto de reconhecimento de contribuições sociais utilizando o conceito de BônusHora Social.

---

# 2. Objetivo da Demonstração

Demonstrar um fluxo completo de:

- participação cidadã;
- registro de ações;
- acompanhamento operacional;
- geração de indicadores;
- rastreabilidade das informações.
