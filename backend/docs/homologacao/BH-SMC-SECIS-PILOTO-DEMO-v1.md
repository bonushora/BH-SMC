# BH-SMC SECIS PILOTO — Demonstração v1

## Visão Geral

O BH-SMC (BônusHora Social Matching Core) é uma infraestrutura digital para registro, validação e reconhecimento de participação cidadã.

O sistema permite transformar ações socioambientais realizadas por cidadãos em registros verificáveis de contribuição.


---

# Fluxo do Piloto

## 1. Cadastro

O participante é registrado no sistema e recebe uma identidade operacional.


## 2. Participação

O cidadão participa de uma ação socioambiental coordenada.


## 3. Registro

A participação gera um evento registrado no sistema.


## 4. Crédito Social

O participante recebe BônusHoras proporcionais à contribuição realizada.


## 5. Auditoria

O sistema verifica se o saldo apresentado corresponde ao histórico registrado.
