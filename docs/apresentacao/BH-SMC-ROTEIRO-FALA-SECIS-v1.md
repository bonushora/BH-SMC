# BH-SMC — Roteiro de Apresentação Institucional SECIS v1

Data:
2026-08-04


# Abertura

O BH-SMC nasce da necessidade de transformar participação cidadã em informação confiável para gestão pública.


# 1. Contexto

Atualmente muitas ações comunitárias acontecem, mas existe dificuldade em registrar:

- quem participou;
- qual atividade foi realizada;
- qual impacto foi gerado;
- como acompanhar os resultados.


# 2. Proposta

O BH-SMC cria uma infraestrutura digital onde cada participação gera uma trilha verificável.


Fluxo:

Cidadão

↓

Participação

↓

Execução

↓

Validação

↓

Indicadores


# 3. Demonstração

Durante o piloto demonstramos:

- cadastro de participantes;
- cadastro de ações;
- registro de execução;
- aprovação;
- geração automática de registro social.


# 4. Indicadores

O piloto apresenta:

- participantes cadastrados;
- ações monitoradas;
- execuções registradas;
- transações sociais;
- indicadores consolidados.


# 5. Diferencial

O sistema não registra apenas atividades.

Ele cria uma memória operacional das ações cidadãs.


# 6. Próxima Fase

A próxima etapa é validar o modelo em ambiente institucional controlado.


Objetivos:

- acompanhar ações reais;
- coletar evidências;
- medir impacto;
- evoluir indicadores.


# Encerramento

O BH-SMC demonstra uma infraestrutura capaz de conectar participação cidadã, rastreabilidade e gestão baseada em dados.
