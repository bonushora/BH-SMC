# 1. Visão Geral

O BH-SMC (Sistema de Monitoramento Cidadão) é uma infraestrutura digital para acompanhamento, validação e mensuração de participação cidadã em ações socioambientais.

O sistema transforma atividades realizadas pela população em dados verificáveis para apoiar gestão pública baseada em evidências.


---

# 2. O Problema

Iniciativas comunitárias possuem desafios:

- dificuldade de registrar participação;
- baixa rastreabilidade das atividades;
- dificuldade de comprovar impacto;
- ausência de indicadores consolidados.


---

# 3. A Solução

O BH-SMC cria uma trilha digital:

Cidadão

↓

Participação

↓

Execução

↓

Validação

↓

Registro

↓

Indicadores Institucionais


---

# 4. Fluxo Operacional


## Coordenador

Responsável pelo cadastro e acompanhamento das ações.


## Cidadão

Participa de atividades socioambientais registradas.


## Execução

A atividade realizada gera evidência operacional.


## Validação

A execução aprovada gera registro no sistema.


## Indicadores

Os dados consolidados são apresentados no Dashboard SECIS.
