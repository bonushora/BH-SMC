Data:
2026-08-04


# 1. Visão Geral

O BH-SMC (Sistema de Monitoramento Cidadão) é uma plataforma para acompanhamento de participação cidadã em ações socioambientais.

O sistema permite registrar atividades realizadas pela população, validar execuções e transformar participação em indicadores sociais mensuráveis.


# 2. Problema

Projetos comunitários normalmente possuem dificuldade em:

- registrar participação de cidadãos;
- comprovar execução das atividades;
- medir impacto social;
- gerar indicadores confiáveis para gestão pública.


# 3. Proposta

O BH-SMC cria uma trilha digital de acompanhamento:

Cidadão

↓

Participação

↓

Execução

↓

Validação

↓

Registro

↓

Indicadores Institucionais


# 4. Demonstração do Fluxo


## Coordenador

O coordenador cadastra e acompanha ações socioambientais.


## Participante

O cidadão participa de uma ação registrada no sistema.


## Execução

A atividade realizada gera um registro operacional.


## Validação

Após aprovação, o sistema registra a contribuição social.


## Dashboard SECIS

Os indicadores são apresentados em visão executiva.

# 6. Diferencial

O BH-SMC combina:

- rastreabilidade operacional;
- indicadores sociais;
- auditoria;
- histórico versionado;
- governança digital.


# 7. Mensagem Executiva

O piloto demonstra uma infraestrutura capaz de transformar participação cidadã em dados verificáveis para apoiar decisões institucionais.
