# BH-SMC — Cenário Piloto SECIS v1

Data:
2026-08-04


# Cenário

Demonstração de uma ação socioambiental acompanhada pelo BH-SMC.


# Contexto

A SECIS realiza uma ação comunitária de melhoria ambiental.

O objetivo é demonstrar como a participação cidadã pode ser registrada, validada e transformada em indicadores institucionais.


---

# 1. Criação da Ação


O coordenador institucional cadastra uma ação:

Exemplo:

Nome:

Mutirão Socioambiental Salvador


Categoria:

Meio Ambiente


Objetivo:

Mobilização comunitária para melhoria dos espaços urbanos.


---

# 2. Participação Cidadã


Cidadãos são vinculados à ação.


O sistema registra:

- participante;
- ação escolhida;
- vínculo operacional.


---

# 3. Execução


Durante a realização da atividade:

O sistema registra:

- início da execução;
- acompanhamento;
- conclusão.


---

# 4. Validação


Após análise do coordenador:

A execução é aprovada.


O sistema:

- valida a participação;
- registra a operação;
- gera histórico.


---

# 5. Registro Social


A aprovação gera uma transação no Ledger Social.


Resultado:

A participação cidadã passa a possuir registro rastreável.


---

# 6. Dashboard Institucional


Os dados consolidados apresentam:


- participantes envolvidos;
- ações realizadas;
- execuções validadas;
- impacto social gerado.


---

# 7. Resultado Demonstrado


O BH-SMC demonstra a transformação:


Atividade comunitária

↓

Dado verificável

↓

Indicador institucional


---

# Mensagem Executiva


O BH-SMC permite que ações cidadãs deixem de ser apenas eventos isolados e passem a formar uma base de conhecimento para planejamento e avaliação pública.
